# Состояние и сторы

## Что где хранить

| Состояние | Где | Почему |
|---|---|---|
| Открыт ли дропдаун | `ref` в компоненте | Никому больше не нужно |
| Черновик формы | Композабл экрана | Должен исчезнуть вместе с экраном |
| Список с фильтром и страницей | Стор | Переживает переход и возврат |
| Профиль текущего пользователя | Стор | Нужен всему приложению |
| Данные для одной карточки | `useAsyncState` в компоненте | Живут столько же, сколько карточка |

Ошибка в обе стороны заметна не сразу:

- **форма в глобальном сторе** показывает недописанный текст при следующем
  открытии;
- **список в локальном состоянии** перезагружается при каждом возврате на
  страницу и теряет позицию скролла и выбранный фильтр.

## Setup-форма стора

```ts
export const useCharactersStore = defineStore("characters", () => {
  const api = useApi();

  const items = ref<Character[]>([]);
  const pending = ref(false);
  const error = ref<string | null>(null);

  const pagination = usePagination(12);
  const search = useSearchQuery({ minLength: 2 });

  async function load() { /* ... */ }

  return { items, pending, error, pagination, search, load };
});
```

Setup-форма, а не options: она пишется тем же кодом, что и композабл, и
позволяет использовать общие композаблы `@roleplay/shared` прямо внутри стора.
В options-форме `usePagination()` вызвать негде.

## Ловушка: `reactive` разворачивает вложенные ref-ы

Pinia оборачивает результат setup-стора в `reactive()`, который разворачивает
ref-ы **и во вложенных объектах**:

```vue
<!-- ✘ вернёт undefined -->
<nav v-if="store.pagination.totalPages.value > 1">

<!-- ✔ -->
<nav v-if="store.pagination.totalPages > 1">
```

Это ловит `nuxt typecheck` — но только если он входит в обязательные проверки.
Без него ошибка проявляется как «пагинация никогда не показывается».

## Три состояния списка

Загрузка, ошибка и пусто описываются явно:

```vue
<p v-if="store.pending">Загружаем…</p>
<p v-else-if="store.error" role="alert">{{ store.error }}</p>
<p v-else-if="!store.items.length">Ничего не найдено.</p>
<div v-else>…</div>
```

Шаблон, в котором есть только `v-for`, показывает пустой экран и при загрузке, и
при сбое сети. Пользователь не может их различить и просто уходит.

`role="alert"` на сообщении об ошибке: иначе пользователь скринридера не узнает,
что что-то пошло не так.

## Реакция на изменение параметров

```ts
watch(search.applied, () => {
  pagination.reset();   // <- обязательно
  void load();
});
watch(pagination.page, () => void load());
```

Без `pagination.reset()` пользователь ищет, находясь на странице 5, и попадает
на страницу 5 новой выдачи — то есть на пустой экран.

## Ошибки в сторе

Стор превращает ошибку в **текст для пользователя**, а не пробрасывает объект в
шаблон:

```ts
catch (caught) {
  error.value = caught instanceof Error
    ? caught.message
    : "Не удалось загрузить список";
  items.value = [];
}
```

`items.value = []` обязателен: иначе поверх сообщения об ошибке остаётся старая
выдача, и пользователь считает её актуальной.

## Границы стора

Стор владеет состоянием **списка**, а не отдельной сущности. Форма
редактирования живёт в композабле экрана.

Стор **не знает** про HTTP: он вызывает `api.characters.search(...)`, где `api`
— порт из [`api-and-adapters.md`](api-and-adapters.md). Благодаря этому стор
одинаково работает с mock- и http-провайдером.

## Именование

```ts
defineStore("characters", ...)          // ✔ домен
defineStore("components/modals", ...)   // ✔ пространство пакета
defineStore("data", ...)                // ✘ ни о чём
```

Идентификатор стора виден в devtools и в персистентном хранилище — он должен
что-то значить.

## `markRaw` для компонентов в состоянии

```ts
entries.set(key, { component: markRaw(options.component) });
```

Компонент — не реактивные данные. Без `markRaw` Vue оборачивает его определение
в прокси и выдаёт предупреждение, а в отдельных случаях ломает рендер.

`shallowReactive` для карты записей: реактивна сама карта (добавление и
удаление), а props остаются непрозрачными значениями. Глубокая реактивность
здесь только замедляет.
