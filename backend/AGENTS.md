# Правила для `backend/`

Действуют вместе с корневым [`AGENTS.md`](../AGENTS.md).

## Исследование

1. `backend/gotemplate` — эталон структуры, слоёв и именования.
2. Прочитай `internal/app/app.go` затронутого сервиса: composition root
   показывает весь граф зависимостей.
3. Прочитай `internal/infra/http/router.go`: вся поверхность HTTP на одном
   экране.
4. Прочитай `migrations/`: какими данными владеет сервис.

## Границы

- Общего `go.work` нет. Команды запускаются **из каталога модуля**.
- `internal/` принадлежит только своему модулю. Между сервисами импортируется
  `pkg/`.
- Сервис не читает таблицы другого сервиса и не ставит внешний ключ в чужую БД.
- Subject и типы сообщений объявляет владелец. Копия и re-export запрещены.
- Для startup, HTTP-движка, логирования, кеша и адаптеров сначала смотри `kit`.

## Слои

Форма задана [`ADR-0001`](../docs/decisions/0001-thin-service-layer.md);
рабочий пример — `backend/gotemplate`.

```text
cmd/ -> config/ -> internal/query/ (sqlc + Querier)
                -> internal/infra/services/<домен>/
                -> internal/infra/http/
                -> internal/domain/dtos/
                -> pkg/
```

- `internal/domain/models` и `internal/infra/repositories` **не заводятся**,
  пока нет доказанного потребителя.
- Интерфейс объявляется рядом с потребителем и только если у него есть
  потребитель: подмена в тестах или второй адаптер.
- `internal/domain/dtos` — единственный слой форм. Отдельные `request.go` в
  контроллерах не заводятся; `response.go` остаётся как схемы swagger.
- Доменные ошибки — категории `kit/errorsx`; транспорт зовёт
  `ginx.WriteDomainError`. Свой `httperr` не создаётся.

Разбор — [`docs/backend/layers.md`](../docs/backend/layers.md).

## HTTP

- Движок собирает `kit/infra/http.NewEngine`.
- `GatewayRequireAuth()` — единственное место проверки аутентификации, на
  группе роутера. В хендлерах не повторяется.
- Вместо повторной проверки сервис держит `router_test.go`, перебирающий все
  маршруты.
- Realm-роль не является доменной авторизацией: привилегированное действие
  разрешает владелец данных внутри сценария, fail-closed.
- Query-параметры разбираются одной структурой через `ginx.ParseQuery[T]`;
  path — через `p.GetPath*`; тело — прямо в `dtos.*Input`.

Разбор — [`docs/backend/http.md`](../docs/backend/http.md),
[`docs/backend/permissions.md`](../docs/backend/permissions.md).

## sqlc и миграции

- `emit_interface: true` обязателен.
- Override'ы для nullable объявляются по внутреннему имени типа:
  `pg_catalog.int8`, `pg_catalog.int4`, `pg_catalog.bool`.
- Порядок колонок в `SELECT`/`RETURNING` совпадает с порядком в схеме.
- Агрегату и выражению даётся явный тип: `COUNT(*)::bigint`.
- Применённая миграция не переписывается — добавляется следующая пара.
- Файлы с `Code generated ... DO NOT EDIT` меняются только через источник и
  генератор.

- Один позиционный параметр в двух ролях (значение колонки и выражение) даёт
  42P08 в рантайме, а не на генерации: приводите тип явно в каждом
  использовании.

Разбор — [`docs/backend/sqlc-migrations.md`](../docs/backend/sqlc-migrations.md).

## Фоновые задачи

- Взаимное исключение — через `kit/pglock.TryWithinTx`. «Блокировку держит
  другой» не ошибка, а пропуск тика.
- Статус не откатывается из терминального состояния: условие в `WHERE`, а не
  `if` в Go.
- Время и внешние идентификаторы заполняются через `COALESCE`: запоздалый
  источник не затирает уже известное.
- Повторная доставка события обязана быть безопасной.
- Тик ограничен по количеству записей.

Разбор — [`docs/backend/concurrency.md`](../docs/backend/concurrency.md).

## Корневые данные

Засев живёт в `cmd/bootstrap` сервиса-владельца, пишет напрямую через слой
хранилища в обход HTTP и проверки доступа, идемпотентен и завершается. В
compose подключается через `condition: service_completed_successfully`.

Демонстрационные данные в засев не входят — только то, без чего система
неработоспособна.

Разбор — [`docs/backend/bootstrap-data.md`](../docs/backend/bootstrap-data.md).

## Сгенерированные protobuf-сообщения

Только по указателю, включая элементы срезов. `go vet ./...` остаётся без
исключений: `copylocks` здесь не ложное срабатывание.

## Проверка

Из каталога модуля:

```bash
go build ./...
go vet ./...
go test ./...
```

При изменении `.sql` или миграций — сначала `mage generate:sqlc`, затем тесты.
После генерации сгенерированные файлы должны быть либо неизменны, либо их
изменение — осознанная часть задачи.
